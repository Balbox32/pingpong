# Bloomhop

A one-thumb mobile game. Hop a tiny gardener from planet to planet, run a full lap to make each one bloom, and stay ahead of the rising Gloom.

Open `index.html` in any phone or desktop browser. No build step, no dependencies, no assets: every sprite, sound and note of music is generated in code.

- **Tap** (or Space) to hop in the direction your head points. The dotted guide shows where you will land.
- **Run a full lap** to bloom a planet. Blooms in a row build a streak, score more, and push the Gloom back.
- Collect **dew** to unlock new hoppers. Grab **bubbles** for a second chance and **comets** for a ride.
- Watch out for drifting planets, crumbling cookie planets and grumpy spiky ones.

`bloomhop.html` is the page source; `index.html` is the same file wrapped in a standalone HTML document.
